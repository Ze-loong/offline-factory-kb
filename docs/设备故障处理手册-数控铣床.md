# 恒锐模具钢有限公司 数控铣床常见故障处理手册

文件编号：HR-SB-011　版本：A/1　适用设备：机加工车间 VMC850 系列数控铣床　归口部门：设备动力部

## 一、使用原则

本手册供设备员和经过培训的操作工排查常见故障时参考。操作工只能进行本手册中标明"操作工可处理"的检查，其余一律按《安全生产管理制度》中的设备异常上报流程，停机挂牌后报告班组长，由设备员处理。任何检查都必须在急停状态下进行，严禁带电打开电气柜。

## 二、主轴过热

主轴过热是铣床最常见的故障之一，点检时主轴前端温度超过环境温度 +15℃或绝对值超过 55℃即视为温度偏高，超过 60℃必须立即停机。操作工可处理的检查有三项：第一，查看集中润滑泵油标，油位低于下刻线时加注 68# 导轨油，并确认润滑泵按设定周期打油；第二，检查主轴冷却机是否运行，冷却机出水口温度应比环境温度低 2～5℃，冷却机报警或风扇不转的，不得继续加工；第三，回顾当班加工参数，长时间以 8000 r/min 以上高转速连续重切削也会导致温升过快，应降低转速或进给后观察 30 分钟。以上三项都正常但温度仍然偏高的，多为主轴轴承预紧力不当或轴承磨损，必须停机报设备员，由设备员用振动仪检测轴承状态，确认需要更换轴承的，按停机超过 4 小时的情形报设备动力部经理，安排外委维修。主轴轴承更换后须进行不少于 2 小时的阶梯式跑合，从 1000 r/min 开始逐级升速，每级运行 20 分钟，期间主轴温度不得超过 50℃。

## 三、主轴异响与振动

主轴低速空转时出现尖叫声，通常是润滑不足或轴承早期磨损；出现周期性的撞击声，通常是刀柄与主轴锥孔之间夹有切屑、拉刀机构松动或轴承滚道损伤。发现异响后，操作工应立即停机，不得为了赶工继续加工，因为轴承损伤在高速下会迅速扩大，严重时会导致主轴抱死。操作工可处理的检查是：卸下刀柄，用干净的无纺布擦拭主轴锥孔和刀柄锥面，检查锥面有无切屑、划痕或锈斑，清洁后重新装刀，以 500 r/min 低速空转 1 分钟复听。若异响消失，可恢复生产，并在点检表备注栏记录；若异响仍然存在，或加工表面出现明显振纹，必须挂"故障停用"牌，按设备异常上报流程报告。设备员到场后，先用振动仪在主轴前后轴承位置测量振动值，振动速度有效值超过 2.8 mm/s 的，判定为轴承异常，安排更换；未超过的，再检查拉刀机构碟形弹簧的拉紧力，拉紧力低于规定值的 80% 时须更换碟形弹簧。

## 四、自动换刀故障

换刀过程中出现卡刀、掉刀或换刀报警时，操作工应立即按下急停按钮，不得用手直接去扶正刀具或拉拽刀臂，以免刀臂突然动作造成夹伤。最常见的原因是气源压力不足：机床气压表低于 0.5 MPa 时，主轴松刀力不够，刀具无法顺利拔出，此时应检查车间气源总阀和机床进气过滤器，排放过滤器积水后压力恢复到 0.5～0.7 MPa，即可在手动模式下单步执行换刀动作复位。第二类原因是刀库刀套与主轴不对中，表现为刀具插入刀套时有明显撞击声，这需要设备员用标准检验棒重新校正换刀点，操作工不得自行修改换刀点参数。第三类原因是刀柄拉钉型号不符或拉钉松动，所有刀柄入库前都要由刀具管理员按机床型号核对拉钉，并用扭力扳手按规定扭矩拧紧。换刀故障处理完成后，须连续执行 20 次以上自动换刀试验，全部正常后方可恢复生产。

## 五、常见报警代码

| 报警代码 | 含义 | 操作工可处理 | 处理方法 |
|---|---|---|---|
| AL-1001 | 主轴过热 | 否 | 停机报设备员，按第二节排查 |
| AL-1105 | 润滑油位低 | 是 | 加注 68# 导轨油后复位 |
| AL-1210 | 气压不足 | 是 | 检查气源，压力恢复到 0.5 MPa 以上后复位 |
| AL-2003 | 刀库计数错误 | 否 | 停机报设备员，不得手动转动刀库 |
| AL-3020 | X/Y/Z 轴超程 | 是 | 手动模式反向移出超程区后复位 |
| AL-4100 | 伺服驱动器过载 | 否 | 停机报设备员 |

## 六、维修记录

每次故障处理后，设备员须在设备管理系统中填写故障现象、原因、处理措施、更换的备件和停机时长，维修记录保存期 3 年。同一台设备同一故障 1 个月内重复发生 2 次以上的，由设备动力部组织原因分析。
