# 恒锐模具钢有限公司 模块成品出厂检验标准

文件编号：HR-ZJ-002　版本：C/2　适用范围：H13、P20、Cr12MoV 模块成品出厂检验　归口部门：技术质量部

## 一、总则

本标准规定模块成品出厂前的检验项目、标准值、抽检比例和判定规则。检验由质检部按批进行，同一炉号、同一钢种、同一交货状态的模块为一个检验批。客户合同或图纸另有要求的，按合同或图纸执行，但不得低于本标准。

## 二、检验项目与标准值

| 检验项目 | 检验方法 | 标准值 | 抽检比例 | 判定 |
|---|---|---|---|---|
| 化学成分 | 直读光谱仪，每炉号取样 1 次 | 符合对应钢种牌号成分范围 | 每炉号 1 次 | 任一元素超出范围，整炉号不合格 |
| 交货硬度（退火态 H13） | 布氏硬度计 | ≤ 229 HBW | 按第三节抽检 | 超标的模块退回重新退火 |
| 交货硬度（退火态 Cr12MoV） | 布氏硬度计 | ≤ 255 HBW | 按第三节抽检 | 超标的模块退回重新退火 |
| 交货硬度（预硬态 P20） | 洛氏硬度计，测 5 点 | HRC 30～36，单件硬度差 ≤ 3 HRC | 按第三节抽检 | 不合格的按 P20 工艺卡处理 |
| 内部缺陷 | 超声波探伤 | 无单个当量 ≥ Φ2 mm 的缺陷，无密集缺陷 | 100% 全检 | 有超标缺陷的单件判废 |
| 外形尺寸 | 卷尺、游标卡尺 | 长宽高公差 0～+3 mm（毛坯面） | 按第三节抽检 | 超差可返修的返修，否则判废 |
| 平面度 | 刀口尺、塞尺 | ≤ 0.30 mm/300 mm（铣磨交货） | 按第三节抽检 | 超差返修 |
| 表面粗糙度（铣磨交货） | 粗糙度仪 | Ra ≤ 1.6 μm | 按第三节抽检 | 超差返修 |
| 表面质量 | 目视，必要时磁粉探伤 | 无裂纹、无折叠、无结疤 | 100% 全检 | 有裂纹的单件判废 |
| 标识 | 目视 | 钢种、炉号、规格、件号钢印清晰 | 100% 全检 | 补打标识后放行 |

## 三、抽检比例

| 检验批数量 | 抽检数量 | 判定规则 |
|---|---|---|
| 1～10 件 | 全检 | 不合格件单件处理 |
| 11～50 件 | 抽 20%，且不少于 5 件 | 抽检全部合格则整批合格；有 1 件不合格则加倍抽检，加倍抽检仍有不合格则整批全检 |
| 51 件以上 | 抽 10%，且不少于 10 件 | 同上 |

## 四、不合格品处理

1. 检验判定不合格的模块，由质检员挂红色"不合格"标签，当班移入不合格品隔离区，不得与合格品混放。
2. 技术质量部在 2 个工作日内组织评审，处理方式分为返工返修、让步接收、判废三种。
3. 让步接收必须取得客户书面同意，并由技术质量部经理签字批准；涉及内部缺陷超标、表面裂纹的，一律不得让步接收。
4. 返工返修后的模块须重新按本标准全项检验，合格后方可出厂。

## 五、记录

检验记录和出厂质量证明书（材质证明）一式两份，一份随货交客户，一份由质检部存档，保存期 5 年。
