# 恒锐模具钢有限公司 员工考勤与请假制度

文件编号：HR-RZ-005　版本：A/2　归口部门：人力资源部

## 一、工作时间

1. 行政管理人员：周一至周五，8:30～17:30，午休 12:00～13:00。
2. 生产一线人员：实行两班制，白班 8:00～20:00，夜班 20:00～次日 8:00，具体排班以车间公布的排班表为准。
3. 员工上下班须在厂区门口人脸识别考勤机打卡。

## 二、迟到、早退与旷工

1. 晚于规定时间 30 分钟以内到岗为迟到，提前 30 分钟以内离岗为早退。
2. 每月迟到、早退累计 3 次以内的，每次扣款 20 元；超过 3 次的，从第 4 次起每次扣款 50 元。
3. 迟到或早退超过 30 分钟，或未请假不到岗的，按旷工半天处理；连续旷工 3 天或一年内累计旷工 5 天的，视为严重违纪。
4. 忘记打卡的，须在 2 个工作日内在 OA 系统提交补卡申请，由直属主管确认，每月补卡不超过 3 次。

## 三、请假类型与审批

| 假别 | 说明 | 审批权限 |
|---|---|---|
| 事假 | 无薪，每次不超过 3 天 | 1 天以内：直属主管；1～3 天：部门经理 |
| 病假 | 须提供二级及以上医院证明，按当地规定发放病假工资 | 3 天以内：部门经理；3 天以上：人力资源部 |
| 年休假 | 按国家规定，工龄满 1 年不满 10 年 5 天 | 部门经理，须提前 3 个工作日申请 |
| 婚假 | 3 天（另按当地规定享受延长假） | 人力资源部 |
| 丧假 | 直系亲属 3 天 | 部门经理 |

## 四、请假流程

1. 员工须提前在 OA 系统提交请假申请，写明假别、起止时间和工作交接人。
2. 突发疾病等情况无法提前申请的，须在当天上班时间开始后 1 小时内电话告知直属主管，返岗后 2 个工作日内补办手续。
3. 生产一线人员请假，须由班组长先安排好顶岗人员，再提交审批。
4. 未经批准擅自离岗的，按旷工处理。
