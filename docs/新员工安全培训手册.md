# 恒锐模具钢有限公司 新员工安全培训手册

文件编号：HR-AQ-010　版本：A/1　归口部门：安全环保部、人力资源部

## 一、三级安全教育

新入职员工（含实习生、劳务派遣人员）上岗前必须接受公司级、车间级、班组级三级安全教育，岗前安全培训时间合计不少于 24 学时，未经三级安全教育或考核不合格的，不得上岗。

| 级别 | 组织部门 | 学时 | 主要内容 |
|---|---|---|---|
| 公司级 | 安全环保部 | 不少于 8 学时 | 安全生产法律法规、公司安全制度、消防和应急知识 |
| 车间级 | 所在车间 | 不少于 8 学时 | 车间危险源、设备安全操作规程、劳动防护用品使用 |
| 班组级 | 所在班组 | 不少于 8 学时 | 岗位操作要点、岗位危险点、班组安全活动 |

三级教育结束后进行书面考试，80 分及以上为合格；不合格的补训后补考一次，补考仍不合格的不予上岗。

## 二、师带徒与独立上岗

1. 新员工通过三级安全教育后，由班组指定一名工龄 3 年以上的师傅一对一带教，带教期为 3 个月。
2. 带教期内，新员工不得独立操作数控铣床、平面磨床、真空气淬炉等设备，必须在师傅监护下作业。
3. 带教期满，由车间组织实操考核，考核合格并取得岗位上岗证后方可独立上岗。
4. 叉车、行车等特种设备，必须另行取得特种设备作业人员证，不在师带徒范围内。

## 三、必须牢记的安全规定

1. 进入车间必须穿工作服、劳保鞋，长发盘入工作帽；操作旋转设备严禁戴手套，必须戴防护眼镜。
2. 厂区内除指定吸烟点外全面禁烟，生产车间、油品库、气瓶间、危废暂存间严禁吸烟和携带火种。
3. 动火作业必须先办理《动火作业许可证》，未经审批一律不得动火。
4. 发现设备异常，立即按急停、挂"故障停用"牌，5 分钟内报告班组长，严禁自行拆修。
5. 厂内应急电话为 8119，发生人身伤害、火灾或有毒有害物质泄漏时立即拨打。

## 四、应急与疏散

1. 听到连续的长鸣警报时，立即停止作业，关闭设备电源，按车间墙上的疏散路线图从最近的安全出口撤离，到厂区东侧停车场集合，由班组长清点人数。
2. 发生火灾时，初起火灾可就近使用灭火器扑救；油类火灾严禁用水扑救，应使用泡沫灭火器、干粉灭火器或沙土。
3. 发生烫伤时，立即用流动冷水冲洗 15～20 分钟，不得涂抹牙膏、酱油等，冲洗后送厂医务室处理。
4. 每年组织不少于 2 次全员应急疏散演练，新员工入职后须参加最近一次演练。
